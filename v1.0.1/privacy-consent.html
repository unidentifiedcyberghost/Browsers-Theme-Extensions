Public IP address lookup

Choose whether the new-tab globe should show your public internet IP address.

If you enable lookup

The extension sends a request to api.ipify.org so that service can return the public IP address it sees for your connection. The request is made when the new-tab page opens and then periodically while it is open.

The IP is displayed in the globe HUD. It is not sent to the extension developer. ISP and VPN details are not requested.

Local address and machine metrics

The optional native helper reads a private interface IP, hostname, CPU, RAM, and disk locally. Those values stay on your device and are not sent to ipify.

Declining keeps public lookup off. The theme and local features continue to work; the public-IP display remains unavailable until you opt in from the popup.
